# Markdown 打印版 PDF

> Turn a `.md` file into a print-ready A4 PDF in your browser — zero install, one file, fully offline.
> 把 `.md` 变成可直接打印的 A4 文档：自动分页、自动目录页码、页眉卷名、页脚页码。

**下载 `md-print-pdf.html`，双击打开，把 `.md` 拖进去，点「导出 PDF」。** 不需要装 Node / Python / LaTeX，不需要联网，文件不上传。

---

## 它解决什么问题

用 Markdown 写材料很舒服，但**打印出来通常很难看**：表格被页面从中间切断、没有页码、没有目录页码、标题孤零零留在页尾、中文用英文字体渲染。

浏览器自带的「打印成 PDF」只会按照 CSS 老老实实往下排，遇到跨页就断在那儿。本工具的做法不同：它**用一段 JavaScript 把内容重新排版到一张张固定的 210×297mm 纸盒里**，所以分页点、页码、页眉、表格拆分全都是可控的。

## 特性

| | |
|---|---|
| **自研分页引擎** | 段落按字符二分切分、列表按项拆分、表格按行拆分（跨页自动重排表头）、引用块拆分 —— 而不是交给浏览器随便断 |
| **自动目录 + 页码回填** | 识别文档里的 `#` / `##` 标题自动生成目录，页码由分页结果反查写入，不依赖任何分页库 |
| **目录可点击跳转** | 导出的 PDF 里，目录每一条都是**可点击的内部链接**（点了直接跳到那一页），不是摆设 |
| **多列表格自适应** | 列数 ≥7 的表格自动降字号并放开表头换行，避免表头把列撑宽、把单元格挤成竖排 |
| **页眉 / 页脚** | 页眉显示文档标题（可换成校徽 + 卷名），页脚 `· 第 X 页 / 共 Y 页 ·` |
| **中文打印版式** | 正文仿宋 12pt（小四）· 一级标题小标宋 · 二级黑体 · 三级楷体 · 首行缩进 2 字 · 行距 19pt |
| **标题不落页尾** | 标题离页底太近时自动推到下一页 |
| **纯本地处理** | 只用 `FileReader` 读文件，全程不联网、不上传 |
| **单文件** | 一个 HTML，零依赖，可离线、可复制、可 U 盘带走 |

## 快速开始

1. 下载本仓库的 `md-print-pdf.html`
2. 用 **Chrome / Edge** 打开（双击即可）
3. 把 `.md` 文件拖进页面，或点「选择 .md 文件」
4. 点右上角「导出 PDF」
5. 在打印窗口里，把「目标」选成 **「另存为 PDF」**

> ### ⚠️ 必须勾选「背景图形」
> 展开打印窗口的「更多设置」，勾选**背景图形**。
> 不勾选的话，**表格边框、标题底纹、答案标记的底色会全部消失**，版式会垮掉。

## 和同类工具的差别

网上 md → PDF 的工具很多，但它们大多走的是另一条路：**用 CSS 美化 + 交给浏览器原生分页**。

| | 本工具 | 单文件类竞品<br>（如 md-2-pretty-pdf） | Pandoc + LaTeX | 在线转换站 |
|---|---|---|---|---|
| 安装 | 零（单个 HTML） | 零 | 需装 LaTeX 环境 | 零，但**要上传文件** |
| 中文打印版式 | ✅ 仿宋/黑体/楷体/小标宋 | 字体可选，无版式 | 需自己写模板 | ❌ |
| **自动目录 + 页码回填** | ✅ | ❌ | ✅ | ❌ |
| **每页页眉** | ✅ | ❌ | ✅ | ❌ |
| **表格跨页不烂断** | ✅ 按行拆 + 表头重复 | ❌ 从中间切断 | 部分 | ❌ |
| 段落跨页字符级切分 | ✅ | ❌ | ✅ | ❌ |
| 完全离线 | ✅ | ✅ | ✅ | ❌ |

一句话：**那些工具管"长得好看"，本工具管"打印出来对"**。

### 需要更进阶的功能？用那个

另有一个功能比本工具更全的同类项目：**[xuworker98/md-print-pdf](https://github.com/xuworker98/md-print-pdf)**（Python，2026-09 发布）。

它比本工具多了：KaTeX 数学公式、**PDF 侧边书签**、图表自动编号与交叉引用（`图 1-1` 自动回填）、封面页、超宽表格自动降字号、详细的质检报告，并且明确支持 Windows / macOS / Linux 三平台。

代价是它需要装 **Python ≥3.10 + Node ≥18 + playwright-core** 三件套，且面向工程/技术文档的交付场景。

**选择建议**：如果你的文档有公式、图表编号、需要 PDF 书签 → 用那个。如果你要的是**双击打开就能用、零安装、打中文讲义/试题** → 用这个。两者场景不同，不冲突。

## 已知限制（如实写）

- **中文字体依赖系统**。Windows 效果最佳（仿宋 / 黑体 / 楷体 / 方正小标宋）。macOS 会退到 `STFangsong` / `STKaiti` 等；Linux 需自行安装中文字体，否则会退到默认衬线/无衬线体。
- **不生成 PDF 书签/大纲**。目录是页面内的链接，不是 PDF 大纲（浏览器打印接口不支持写入大纲）。
- **无数学公式、无代码语法高亮**。本工具面向中文文档 / 讲义 / 试题，不是技术文档排版器。需要公式请用 Pandoc、需要高亮请用专门工具。
- **单个超长且不可拆分的内容块**（例如一整个巨大的表格只有一行）理论上会溢出一页，工具会在界面上提示「有 N 页内容过长」。
- 导出依赖浏览器「打印为 PDF」，所以**页边距由本工具的 CSS 决定**，不要在打印窗口里再改缩放（保持「默认」）。

## 换成你自己的校徽

默认不带任何徽章。想加上自己学校/单位的校徽：

**方法一（推荐）**：用构建脚本

```bash
python tools/build.py --main 你的校徽.png --secondary 你的徽章.png
```

它会读 `tpl-oss.html` + `marked.min.js` + 你的两张 PNG，生成新的 `md-print-pdf.html`。

**方法二（手动）**：打开 `md-print-pdf.html`，找到这两行，把空字符串换成你的 base64 data URI：

```js
var CREST_SRC  = '';   // 主徽章，页眉左上角，实渲 14mm
var CREST2_SRC = '';   // 次徽章，跟在主徽章右侧，实渲 12mm
```

建议素材为**正方形、透明底 PNG，边长 ≥ 600px**（14mm 下约 1000 PPI 以上最稳）。

## 自定义版式

`md-print-pdf.html` 里的 `<style>` 段开头有完整注释。常用的几个：

| 想改什么 | 找什么 |
|---|---|
| 页边距 | `.pg-body { top / left / right / bottom }`（默认 上26 / 下16 / 左25 / 右15 mm） |
| 左边距为什么是 25mm | 给装订/长尾夹预留的。不需要就改成 15mm（同时改 `.pg-header` 和 `.pg-footer` 的 `left`） |
| 正文与行距 | `.pg-body { font-size: 12pt; line-height: 19pt }` |
| 各级标题字体 | `.pg-body h1` / `h2` / `h3` 的 `font-family` |
| 主色 | 搜索 `#0f766e`（墨绿）替换 |
